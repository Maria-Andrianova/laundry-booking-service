# СтирайБезОчереди

Веб-сервис для бронирования стиральных и сушильных машин в общежитии. Курсовой проект: «Разработка системы мониторинга и бронирования ресурсов студенческого общежития».

В общежитии на 1200 человек работают 5 стиральных и 3 сушильные машины, и узнать заранее, какая из них свободна, было невозможно. Сервис показывает статус каждой машины и позволяет записаться на удобное время.

## Возможности

- Регистрация и вход, личный кабинет с историей бронирований.
- Бронирование машины на выбранную дату и время с проверкой пересечений.
- Статусы машин в реальном времени: свободно, занято, на ремонте.
- Рейтинг пользователей: за несвоевременное освобождение машины рейтинг снижается, а от рейтинга зависит, на сколько дней вперёд можно бронировать.
- Подтверждение пунктуальности предыдущего пользователя.
- Сообщения о неисправностях машин.
- Панель администратора: управление машинами, история бронирований с фильтрами, статистика загрузки.

## Структура

- `src/`: PHP-скрипты и стили.
- `database/schema.sql`: создание базы данных и таблиц, пример данных о машинах.
- `docs/`: пояснительная записка курсового проекта (PDF).

## Технологии

PHP, MySQL, HTML, CSS, JavaScript.

## Запуск

1. Установить [XAMPP](https://www.apachefriends.org) (Apache, PHP и MySQL) и запустить Apache и MySQL.
2. Открыть phpMyAdmin (`http://localhost/phpmyadmin`), перейти на вкладку «Импорт» и загрузить файл `database/schema.sql`.
3. Скопировать содержимое папки `src` в папку `htdocs/laundry` в каталоге XAMPP.
4. Открыть в браузере `http://localhost/laundry/login.php` и зарегистрироваться.
5. Чтобы получить права администратора, в phpMyAdmin в таблице `users` у нужного пользователя установить `is_admin` равным 1.

Параметры подключения к базе данных находятся в `src/db.php` (по умолчанию стандартные для XAMPP: пользователь `root`, пароль пустой).
